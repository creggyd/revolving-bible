# Revolving Bible

**A Connected Scripture Experience for Individuals and Churches**

**Project Owner / Founder:** Craig Francis  
**Document Owner:** Revolving Bible Project  
**Project Status:** Prototype established; commercial development planning  
**Version:** 1.0

---

## 1. About the Project

Revolving Bible is a cross-platform Christian Scripture application designed to make Bible passages accessible throughout everyday life and church services.

The platform combines an automatic rotating Scripture display, preacher-controlled Bible readings, QR-based Scripture sharing and individual Bible engagement features.

Its central purpose is to connect individuals and church congregations through a shared, accessible Scripture experience.

## 2. Our Vision

To create a reliable, engaging and accessible Scripture platform that helps individuals and churches keep God's Word present in everyday life and worship.

The application is being designed to serve Christians across different denominations without promoting a particular denominational tradition.

## 3. Key Features

### Individual Experience
- Daily Scripture passages.
- Automatic Scripture rotation.
- Saved and favourite passages.
- Scripture sharing.
- Church-neutral biblical reflections.
- Scripture of the Week.

### Church Experience
- Automatic revolving Bible display.
- Synchronised Scripture across multiple screens.
- Preacher-controlled Scripture readings.
- QR-based Scripture sharing with congregations.
- Church-specific Scripture collections.
- Church administration and device management.

### Connected Experience
- Centralised Scripture library.
- Cloud-based synchronisation.
- Multiple device support.
- Secure church accounts.
- Cross-platform accessibility.

## 4. Scripture Library

The current prototype contains 30 active King James Version (KJV) passages.

The commercial Version 1.0 target is a minimum of 365 passages, with the ability to expand to 1,000 or more.

Passages will be organised into meaningful categories to support Scripture discovery and daily engagement.

## 5. Technology Stack

The current prototype uses:

- GitHub Pages – Initial web hosting.
- Supabase – Database and backend services.
- PostgreSQL – Database engine.
- JavaScript – Current application functionality.

The proposed commercial architecture will expand to include:

- Ionic and React – Cross-platform application interface.
- Capacitor – Android and iOS deployment.
- Supabase Auth – User authentication.
- Supabase – Cloud backend and database services.

## 6. Target Platforms

- Android smartphones and tablets.
- Apple iPhones.
- Apple iPads.
- Web browsers.
- Church presentation screens.

## 8. Development Approach

The project will be developed in clearly defined stages:

1. Complete and stabilise the existing prototype.
2. Establish the commercial database and security architecture.
3. Develop individual and church account functionality.
4. Build the Android and iOS applications.
5. Implement advanced church features.
6. Conduct testing and prepare for commercial release.

All significant source-code changes, database modifications and technical decisions will be documented and version-controlled through GitHub.

## 9. Source Code and Project Maintenance

GitHub is the official source-code repository.

Development standards include:

- Maintain version history.
- Document significant code changes.
- Preserve working versions.
- Maintain database migration scripts.
- Protect backend credentials.
- Keep independent database backups.
- Maintain technical documentation.

## 10. Project Direction

Revolving Bible is being developed as more than a conventional Bible-reading application.

Its distinguishing feature is the connection between individual Scripture engagement and synchronised church Scripture presentation.

The long-term objective is to establish a scalable platform that serves both individual believers and church organisations.
